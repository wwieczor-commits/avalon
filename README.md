# BR AVALON Sp. z o.o. – strona www

Strona internetowa biura BR AVALON w Rzeszowie (ul. Mieszka I 48/50).

- `index.html` – usługi księgowe (strona główna)
- `leasing.html` – doradztwo leasingowe
- `siedziba.html` – siedziba i adres firmy
- `polityka-prywatnosci.html` – informacja RODO
- `styles.css`, `app.js` – wspólny wygląd i zachowanie stron
- `br-avalon-logo.svg`, `br-avalon-logo.png`, `logo-mark.svg` – logo

Strona to statyczne pliki. Formularz wysyła wiadomość na kdec@bravalon.pl przez FormSubmit. Przy pierwszym użyciu skrzynka musi kliknąć link aktywacyjny, który przyjdzie na ten adres.
