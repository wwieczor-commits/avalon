# BR AVALON Sp. z o.o. – strona www

Strona internetowa biura BR AVALON w Rzeszowie (ul. Mieszka I 48/50).

- `index.html` – usługi księgowe (strona główna)
- `leasing.html` – doradztwo leasingowe
- `siedziba.html` – siedziba i adres firmy
- `polityka-prywatnosci.html` – polityka prywatności (RODO)
- `assets/fonts/` – czcionki trzymane lokalnie (bez Google Fonts)
- `sitemap.xml`, `robots.txt`, `assets/og-image.jpg` – SEO i podgląd linku
- `br-avalon-logo.svg`, `br-avalon-logo.png`, `logo-mark.svg` – logo

Strona to statyczne pliki HTML – wystarczy wrzucić je na dowolny hosting lub włączyć GitHub Pages.
